# Prompt: Revisi Section "Ikuti Kami" — Tampilan Mobile

## Konteks
Section "Ikuti Kami" (Instagram, Facebook, YouTube, Twitter/X) di footer landing page SAPADA perlu disesuaikan khusus untuk tampilan mobile. **Jangan ubah theme (dark mode) atau font.**

## Perubahan yang Diminta

1. **Judul dan deskripsi section "Ikuti Kami" dibuat center-aligned** (khusus tampilan mobile).

2. **Card sosmed di mobile hanya menampilkan icon platform saja** — tanpa nama platform (Instagram/Facebook/YouTube/Twitter) dan tanpa username/handle (@bapendagarut, dll). Bukan lagi card persegi panjang berisi teks, cukup icon-nya saja.

3. **Keempat icon (Instagram, Facebook, YouTube, Twitter/X) disusun dalam 1 row horizontal**, bukan grid 2x2 seperti sekarang, dan barisnya di-center secara horizontal.

4. **Teks di bawahnya** — "Dapatkan berita terbaru, sosialisasi perda, dan pengumuman jatuh tempo pajak." — **dibuat center-aligned** khusus di tampilan mobile.

## Catatan
- Perubahan ini spesifik untuk breakpoint mobile. Jika ada tampilan desktop/tablet terpisah, tidak perlu diubah kecuali diminta.
- Pertahankan warna, style icon, dan font yang sudah ada — hanya ubah layout (alignment, susunan row, dan penyederhanaan card jadi icon-only).
